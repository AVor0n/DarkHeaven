# 03. Интерфейс и ощущения

## 1. Экраны

```
Главное меню ─┬─ Новая партия ── Партия ── Итоги
              ├─ Продолжить (если есть автосохранение)
              ├─ Как играть (краткие правила своими словами + памятка хода)
              ├─ Настройки
              └─ Онлайн (этап 2)
```

### 1.1. Главное меню

Тёмный экран, в центре свеча с дрожащим пламенем, название DarkHeaven, тихий
эмбиент. Пункты меню проявляются из тьмы при наведении.

### 1.2. Новая партия

- Число игроков 1–5 и имена; распределение узников показывается автоматически по правилам.
- Набор правил: базовые / расширенные; боссы (Неотвратимые 0/2/3, Плакальщик);
  дополнение (конструктор монстров) — включаются по мере реализации этапов.
- Сложность: ключи ±, врата −1, «хаос».
- Подсказки: обычные / хардкор.
- Seed: случайный или ввести вручную («сыграть тот же расклад»).

### 1.3. Экран партии (десктоп)

```
┌──────────────────────────────────────────────────────────────┐
│ Ход 12 · Зелёный (Андрей)       [свеча-запас: 41]   ⚙  ☰    │
├────────────┬───────────────────────────────┬─────────────────┤
│ Узники     │                               │ Сброс по типам  │
│ ● Красный  │         ПОЛЕ (тор)            │ ключи 1/6 …     │
│   🔥 ◆◆ 🗝 │                               ├─────────────────┤
│ ● Жёлтый   │                               │ Журнал событий  │
│   ✖ ◆  —   │                               │ …               │
│ …          │                               │                 │
├────────────┴───────────────────────────────┴─────────────────┤
│ Подсказка: «Выберите, куда идти»   [Остаться] [Рывок] [Готово] │
└──────────────────────────────────────────────────────────────┘
```

- **Свеча-запас**: оставшиеся плитки показаны тающей свечой с числом. В последнем
  мерцании пламя трепещет и гаснет, вокруг поля сгущается тьма.
- **Планшет сброса**: счётчики по типам (ключи, врата, монстры, проходы) —
  чтобы видеть, насколько близко поражение.
- **Узники**: цвет и буква (для дальтоников), состояние свечи, решимость 0–2,
  ключ, «падает (строка 3)», кто управляет.
- **Журнал**: человеческие фразы («Синий спровоцировал пожирателя воска:
  Красный и Синий теряют по 3 плитки»). Клик по записи подсвечивает клетки.

### 1.4. Итоги

Победа или поражение с причиной, статистика (ходы, атаки, сброшено плиток,
падения), кнопки «Ещё раз», «Тот же расклад», «Сохранить реплей».

## 2. Поле и тор

- Поле N×N с «призрачной» каймой: по краям видна половина клеток с
  противоположной стороны, чтобы перенос через край был очевиден.
- **Камера следует за активным узником**: поле циклически сдвигается так, чтобы
  активный узник был ближе к центру. Сдвиг анимирован, отключается в настройках.
- Пустые клетки — тьма. Освещённые плитки видны, неосвещённые растворяются
  в темноте при сбросе.
- Canvas-слой света поверх поля: радиальное мерцающее свечение вокруг каждого
  узника с горящей свечой, тусклое пятно вокруг погашенного.

## 3. Ввод

### 3.1. Выбор хода

- Допустимые клетки для перемещения подсвечены; монстры с рывком — отдельным цветом.
- Наведение на клетку показывает **превью последствий**: обрушение, какие монстры
  атакуют, кто пострадает, сколько плиток уйдёт из запаса (до уклонений), падение,
  ключ, повторное зажигание. Скрытые плитки запаса превью не раскрывает.
- Клик выбирает клетку, кнопка «Готово» (или повторный клик/Enter) подтверждает.
- «Остаться на месте» — кнопка и клавиша Space; превью: «+1 решимость, тянете 1 плитку».

### 3.2. Выкладка плитки

- Вытянутая плитка показывается крупно рядом с полем.
- Подсвечены клетки, куда её можно положить; клик ставит плитку в первом
  допустимом повороте; колесо мыши, R или кнопки ⟲ ⟳ перебирают только
  допустимые повороты; «Готово» подтверждает.
- Превью при выкладке монстра: его будущая линия видимости.

### 3.3. Прочие решения

Падение (строка или столбец), клетка приземления, уклонение, замена монстром,
сброс в последнем мерцании, позиция Плакальщика, цель пожирателя света — всё
через подсветку на поле и короткую строку в панели действий. Модальных окон нет,
кроме подтверждения «Сдаться».

### 3.4. Клавиатура

Стрелки/WASD — выбрать направление, Space — остаться, R/Shift+R — повернуть,
Enter — подтвердить, Esc — отменить выбор, L — показать все линии видимости,
1/2 — тратить решимость.

## 4. Подсказки

| Подсказка | Обычный | Хардкор |
|---|---|---|
| Подсветка допустимых ходов | да | да |
| Линия видимости монстра при наведении | да | нет |
| Все линии видимости (клавиша L) | да | нет |
| Превью последствий хода | да | нет |
| Предупреждение «этот ход приведёт к поражению» | да | нет |

## 5. Анимации

Плавное перемещение фишки, «вспышка» атаки по линии с дрожанием экрана,
отлёт сброшенных плиток к свече-запасу, обрушение с трещинами, падение с
затуханием, проявление новых плиток из тьмы. Скорость: обычная / быстрая / без
анимаций; соблюдается `prefers-reduced-motion`.

## 6. Звук

Эмбиент подземелья, музыка в меню и звуковые эффекты: шаги, выкладка и
обрушение плитки, падение, рык и атака монстра (у каждого типа свой), свеча
гаснет и загорается, ключ, решимость, начало последнего мерцания, победа,
поражение. Громкость по каналам (музыка, эффекты, эмбиент), кнопка «без звука».

## 7. Хотсит

Скрытой информации у игроков нет, поэтому экран передачи хода не нужен.
Активный узник и управляющий им игрок крупно подписаны; при смене игрока
короткая плашка «Ход Ольги».

## 8. Доступность

- Узники различаются не только цветом: буква и форма метки.
- Контраст текста не ниже WCAG AA, размер шрифта настраивается.
- Полное управление с клавиатуры, видимый фокус.
- Режим уменьшенного движения.

## 9. Сохранения

- Автосохранение после каждого действия в `localStorage` (seed + список действий).
- «Продолжить» в меню восстанавливает партию.
- Реплеи сохраняются локально и экспортируются в файл JSON.
