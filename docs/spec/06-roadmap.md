# 06. Этапы

Каждый этап — один или несколько PR в `main`. После каждого мержа сайт на
GitHub Pages обновляется автоматически.

## Этап 1 — MVP (соло и хотсит, базовые правила)

| Веха         | Содержание                                                                                        | Готово, когда                                               |
| ------------ | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| M0 Каркас    | монорепо, Biome, TS, Vitest, CI, деплой заглушки на Pages                                         | CI зелёный, страница открывается по ссылке                  |
| M1 Движок    | базовые правила по [01-rules.md](01-rules.md), превью, реплеи                                     | сценарии из правил и фаззинг 2000 партий проходят           |
| M2 Интерфейс | меню, новая партия, поле с тором и камерой, все решения, подсказки, журнал, итоги, автосохранение | партию от начала до конца можно сыграть мышью и клавиатурой |
| M3 Атмосфера | процедурные плитки, эмблемы, слой света, анимации, звук                                           | визуальная проверка, звук отключается и регулируется        |
| M4 Полировка | «Как играть», настройки, доступность, реплеи, e2e                                                 | e2e зелёные, Lighthouse a11y ≥ 90                           |

## Риски

| Риск                                                                    | Как снижаем                                                                                              |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Неоднозначности правил всплывают при игре                               | трактовки собраны в таблицах, движок покрыт сценарными тестами, правка = одна функция                    |
| Сгенерированный арт не стыкуется на поле                                | проходы процедурные, нейросеть рисует только эмблемы                                                     |
| GitHub Pages недоступен для приватного репозитория на бесплатном тарифе | при отказе деплоя — попросить Андрея включить Pages или сделать репозиторий публичным (сканов в нём нет) |
| Онлайн требует хостинга                                                 | этап 2, выбор провайдера за Андреем                                                                      |
