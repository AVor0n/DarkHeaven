# 05. Ассеты

## 1. Стиль

Белая и костяная гравюра (scratchboard) на угольно-чёрном фоне, тонкие
штрихи, макабрические существа, тёплые отсветы свечи. Ориентир — оригинальная
игра, но все изображения свои. Палитра:

| Токен | Цвет | Где |
|---|---|---|
| `--void` | #07060a | фон, тьма |
| `--stone` | #16131a | плитка |
| `--bone` | #e9e0cf | проходы, гравюра |
| `--wax` | #f3c77a | пламя, акценты |
| `--ember` | #c2461f | атака, опасность |
| `--spirit` | #8fa7c9 | решимость |
| узники | #d8423a, #e5c02f, #4fa65b, #3e7fd1, #9a5cc9 | красный, жёлтый, зелёный, синий, фиолетовый |

## 2. Плитки: процедурные проходы + эмблемы

Чтобы стыки плиток совпадали идеально, **проходы рисуются процедурно** (SVG):
единая ширина коридора, неровные края по детерминированному шуму от id плитки,
трещины у разрушающихся плиток. Поверх кладётся **эмблема** — сгенерированная
картинка с чёрным фоном в режиме наложения `screen`, поэтому прозрачность не нужна.

| Эмблема | Плитки |
|---|---|
| Руна старта (каменный круг) | стартовые |
| Ключ | плитки с ключом |
| Врата (череп-портал) | врата |
| Пожиратель воска (вихрь когтистых рук) | пожиратели воска |
| Яма (провал с кромкой) | рубашка любой плитки |
| Хранитель ключа (спрут с ключом, явный «рот») | этап 2 |
| Исчадие тьмы (тёмная сфера с двумя огнями) | этап 2 |
| Предвестник (глаз в оправе) | этап 2 |
| Неотвратимый | этап 2 |
| Плакальщик 3×3 и его яма | этап 2 |
| Пожиратель света, прерыватель пути, Несущий Конец | этап 3 |

Интерфейс: фишки-свечи узников (SVG, тонируются цветом), жетоны решимости и
ключа, свеча-запас, фон меню, иллюстрации победы и поражения, иконка приложения.

## 3. Каталог плиток

Каталог в движке (`packages/engine/src/content/tiles.ts`) задаёт для каждого
физического экземпляра: id, тип, выходы в повороте 0, разрушаемость, эмблему,
вариант рисунка прохода. Состав и выходы — по таблице из [01-rules.md](01-rules.md#2-плитки)
и [02-extended-rules.md](02-extended-rules.md). Для справки: в сканах (`тайлы.pdf`)
102 лица плиток (нечётные страницы) и рубашки (чётные), по 519×519 px.

## 4. Генерация изображений (kie.ai)

- Скрипт `scripts/gen-images.mjs`: промпт из `scripts/prompts/images/*.json`
  (общий стиль + описание объекта), модель генерации изображений kie.ai,
  квадрат 1024×1024, затем обработка `sharp`: чёрный фон, обрезка, виньетка,
  экспорт в WebP 512 px.
- Результаты коммитятся в `apps/web/public/assets/art/`; промпты и seed —
  рядом, чтобы ассет можно было перегенерировать.
- Ключ API — только переменная окружения `KIE_API_KEY`.

## 5. Звук (kie.ai)

| Ассет | Тип | Длительность |
|---|---|---|
| Эмбиент подземелья (капли, гул, далёкие шорохи) | цикл | 60–120 с |
| Музыка меню (тёмный эмбиент, виолончель) | цикл | 60–120 с |
| Шаг по камню | SFX | <1 с |
| Выкладка плитки (камень по камню) | SFX | <1 с |
| Обрушение плитки | SFX | 1–2 с |
| Падение (свист и далёкий удар) | SFX | 1–2 с |
| Рык и атака пожирателя воска | SFX | 1–2 с |
| Свеча гаснет / загорается | SFX | <1 с |
| Ключ взят | SFX | <1 с |
| Решимость получена / потрачена (удар сердца) | SFX | <1 с |
| Последнее мерцание (треск угасающего пламени, низкий тон) | SFX | 2–3 с |
| Победа (скрип врат, светлый аккорд) / поражение | SFX | 3–5 с |
| Клики интерфейса | SFX | <0.3 с |

- Эффекты — модель звуковых эффектов, музыка — модель генерации музыки, обе через kie.ai.
- Обработка `ffmpeg`: нормализация громкости, обрезка тишины, экспорт в
  `.webm` (Opus) и `.mp3` как запасной вариант.
- Видео (интро) — опционально в полировке, не входит в MVP.
