# DarkHeaven — спецификация веб-версии «Обители тьмы»

DarkHeaven — браузерная версия кооперативной настольной игры «Обитель тьмы»
(Smirk & Dagger, 2023; русское издание Hobby World / «Магеллан»). Узники
с догорающими свечами выкладывают лабиринт вокруг себя, ищут ключи и пытаются
вместе добраться до врат, пока тьма поглощает пройденные коридоры.

Спецификация собрана по итогам интервью с Андреем (22.10.2026). Решения,
которые Андрей принял сам, помечены как **[А]**. Остальные Андрей делегировал,
они помечены как **[C]** и могут быть пересмотрены в любой момент.

## Цели

1. Играбельная в браузере версия «Обители тьмы», в которой компьютер следит
   за всеми правилами, а игроки принимают только содержательные решения.
2. Атмосфера оригинала: тьма, дрожащий свет свечей, исчезающие коридоры.
3. Движок правил, пригодный и для локальной игры, и для онлайн-кооператива.

## Не цели (пока)

- Коммерческий релиз, монетизация, аккаунты, рейтинги.
- ИИ-напарники. В соло один человек ведёт всех узников, как в официальных правилах.
- Мобильная вёрстка под телефон в портретной ориентации (будет позже).

## Глоссарий

Русские термины совпадают с русским изданием правил, английские используются в коде.

| Русский                  | В коде                 | Комментарий                                                       |
| ------------------------ | ---------------------- | ----------------------------------------------------------------- |
| узник                    | `prisoner`             | фишка игрока; узников всегда 4 (при 5 игроках — 5)                |
| фрагмент, плитка         | `tile`                 | квадратная плитка лабиринта, лицо и сторона с ямой                |
| запас фрагментов (свеча) | `pile`                 | закрытая стопка; её размер — «оставшийся воск»                    |
| планшет сброса           | `discard`              | открытый сброс, виден всегда                                      |
| клетка                   | `cell`                 | позиция на поле N×N, поле замкнуто в тор                          |
| выход, проход            | `exit`                 | сторона плитки, по которой можно пройти                           |
| яма                      | `pit`                  | перевёрнутая плитка; падение в неё переносит узника               |
| разрушающийся фрагмент   | `crumbling`            | обваливается в яму, когда узник уходит с него или остаётся на нём |
| свеча горит / погашена   | `lit` / `extinguished` |                                                                   |
| жетон решимости          | `resolve`              | максимум 2 у узника                                               |
| ключ / врата             | `key` / `gate`         |                                                                   |
| пожиратель воска         | `waxEater`             | базовый монстр                                                    |
| линия видимости          | `sight`                | откуда монстр замечает движение                                   |
| зона атаки               | `attackArea`           | по кому бьёт атака (у большинства совпадает с линией видимости)   |
| последнее мерцание       | `lastFlicker`          | фаза после опустошения запаса                                     |
| хранитель ключа          | `keyKeeper`            | расширенные правила                                               |
| исчадие тьмы             | `darkSpawn`            | расширенные правила                                               |
| Неотвратимый             | `inevitable`           | босс                                                              |
| Плакальщик / предвестник | `mourner` / `herald`   | босс и его таймер                                                 |
| пожиратель света         | `lightEater`           | дополнение                                                        |
| прерыватель пути         | `pathBreaker`          | дополнение                                                        |
| Несущий Конец            | `endBearer`            | дополнение, босс                                                  |
