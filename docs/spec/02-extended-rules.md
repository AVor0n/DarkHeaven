# 02. Расширенные правила, боссы, дополнение, сложность

Всё ниже включается переключателями на экране новой игры и реализуется поверх
базового движка как данные о плитках плюс обработчики событий
(«при выкладке», «при вытягивании», «при атаке», «после атаки»).

## 1. Модель монстра

```ts
interface MonsterDef {
  sightDirs(rotation): Dir[]; // направления линии видимости
  attackArea(board, cell, rotation): Cell[];
  onHit(prisoner): Effect; // последствия попадания
  afterAttack: 'remove' | 'pit-if-lit' | 'stay';
  onReveal?: Effect; // активация при вытягивании
  onPlace?: Effect; // активация при выкладке
  chainFromTopBlocked?: boolean; // хранитель ключа
}
```

## 2. Расширенные правила

**Подготовка:** убрать все плитки с ключом и 8 пожирателей воска (остаётся 4),
добавить 6 хранителей ключей (7 при 5 игроках) и 2 исчадия тьмы. Опция: третье исчадие.

### 2.1. Хранитель ключа

- Плитка-перекрёсток с «ртом». При выкладке поворачивается ртом к узнику, чей
  выход заполняется (поворот не выбирается). «Верх» — сторона напротив рта.
- Остаётся на поле, даже если клетка не освещена, пока с него не взяли ключ.
- Вход с «верха» безопасен и не провоцирует хранителя. Вход с других сторон —
  только рывком и с атакой (−3, гаснет).
- Попав на хранителя, узник берёт ключ, если его нет. В любом случае плитка
  переворачивается ямой (ключ пропадает), а узник сразу делает вынужденное
  перемещение.
- Падение на хранителя — как вход не с «верха»: атака, затем ключ и переворот.
- Атака другого монстра, пришедшая в хранителя с «верха», цепную реакцию не вызывает.
- Хранители на поле и в запасе считаются источниками ключей в проверке поражения.

### 2.2. Исчадие тьмы

- Срабатывает сразу при выкладке: каждая плитка на диагоналях от него
  (во все 4 стороны до края поля, без переноса через край, сквозь пустые клетки)
  переворачивается ямой — включая ключи, врата и монстров.
- Затем само исчадие становится ямой.
- Узники на новых ямах падают сразу, даже в чужой ход; падение провоцирует
  монстров по §5.2 базовых правил.
- Исчадие не сбрасывает плитки из запаса и не гасит свечи.
- Узник, приземлившийся на исчадие, падает снова. ⚠ E1

## 3. Монстры-боссы

Включаются отдельно и в базовой, и в расширенной игре.

### 3.1. Неотвратимые

Добавить 2 плитки в запас (опция: 3). Активируются как пожиратель воска, но зона
атаки — вся строка и весь столбец. Попадание: −5, свеча гаснет, уклониться нельзя.

### 3.2. Плакальщик

- В запас добавляются 2 предвестника.
- Первый открытый предвестник откладывается рядом с полем, вместо него сразу
  тянется следующая плитка. Так же при сбросе от атаки и при «остаться». ⚠ E2
- Второй предвестник кладётся на поле как обычная плитка (если открыт при сбросе
  или при «остаться» — заменяет соседнюю освещённую плитку). Тут же активный
  игрок выбирает позицию жетона Плакальщика 3×3: он накрывает предвестника и
  не выходит за края поля (без переноса). Превью всех допустимых позиций.
- Всё под жетоном уходит в сброс. Узники под ним: −3 (уклонение можно), свеча
  гаснет, затем падение.
- Жетон становится ямой 3×3. Она исчезает целиком, когда ни одна её клетка не освещена.

## 4. Фанатское дополнение «Набор монстров»

Подготовка по умолчанию: 6 пожирателей воска, 4 пожирателя света, 2 прерывателя
пути. Конструктор набора: новые монстры заменяют пожирателей воска один к одному;
опция «добавить без замены» для повышенной сложности.

### 4.1. Пожиратель света

- Срабатывает сразу, когда его вытянули для выкладки (включая «остаться на месте»).
  Сброс из запаса при атаке его не активирует. ⚠ E3
- Цель — один **изолированный** узник с горящей свечой: на ортогонально соседних
  клетках нет других узников. ⚠ E4 Цель выбирает активный игрок, можно себя.
- Свеча цели гаснет. Если изолированных узников с горящей свечой нет — эффекта нет.
- Затем плитка кладётся ямой в ту клетку, куда её тянули, если клетка
  освещена; иначе уходит в сброс.
- Узник, приземлившийся на пожирателя света или вошедший на него в темноте,
  гасит свечу (даже не будучи изолированным), монстр атакует другую цель,
  затем плитка становится ямой и узник падает снова.

### 4.2. Прерыватель пути

- Плитка с двумя «лицами» на противоположных сторонах (выходы N, S). Выкладывается
  так, чтобы одно лицо смотрело на выкладывающего узника (следует из правила соединения).
- При выкладке не атакует. Провоцируется как пожиратель воска, но видит только вдоль оси лиц.
- Атака: все плитки в строке/столбце оси (весь ряд тора) становятся ямами,
  узники на них падают.
- После атаки: яма, если клетка освещена, иначе сброс.
- Узник, попавший на прерыватель по любой причине, сбрасывает 3 из запаса, затем
  прерыватель атакует (при приземлении — вдоль выбранной линии падения), становится
  ямой, и узник падает снова.
- Вытянут погашенным узником при входе в пустую клетку — атакует вдоль
  направления движения.

### 4.3. Приближающий конец (Несущий Конец)

- В запас добавляются 5 предвестников. Каждый открытый откладывается, вместо него
  тянется следующая плитка.
- При пятом появляется Несущий Конец: его жетон лежит на запасе. С этого момента
  в конце каждого хода сбрасывается верхняя плитка запаса, пока не начнётся
  последнее мерцание.
- Вместе с Плакальщиком: те же 5 предвестников, второй вызывает Плакальщика, пятый — Несущего Конец.

## 5. Настройки сложности

| Опция                   | Эффект                                                    |
| ----------------------- | --------------------------------------------------------- |
| +1 / +2 ключа           | легче (не больше, чем есть плиток в коробке)              |
| −1 ключ                 | сложнее                                                   |
| −1 врата                | сложнее                                                   |
| Хаос                    | 2 обычных Т заменяются разрушающимися                     |
| Мрачная тишина (онлайн) | чат доступен только между узниками на соединённых клетках |

## Трактовки

| #   | Место                                       | Решение                                                                                                                                            |
| --- | ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| E1  | Приземление на исчадие тьмы                 | Исчадие срабатывает, его клетка становится ямой, узник падает снова без потерь                                                                     |
| E2  | Предвестник при сбросе/«остаться»           | Первый откладывается и замещается следующей плиткой, второй ведёт себя как монстр при «остаться»                                                   |
| E3  | Пожиратель света из сброса                  | Не срабатывает — «повезло», как с пожирателем воска                                                                                                |
| E4  | «Рядом с другими заключёнными»              | Ортогональные соседи с учётом тора, независимо от проходов; узники на одних вратах не изолированы                                                  |
| E5  | Предвестник Плакальщика при сбросе от атаки | Лежит рядом с полем до конца атаки, затем заменяет плитку рядом с узником, чей сброс его открыл (если тот упал — рядом с активным)                 |
| E6  | Пожиратель света при «остаться»             | Срабатывает (гасит изолированного) и уходит в сброс: клетки, куда его тянули, нет                                                                  |
| E7  | Попадание прерывателя пути                  | Узник на самом прерывателе: −3 (уклонение можно), свеча не гаснет. Остальные в ряду падают без сброса; их падение провоцирует монстров вне цепочки |
| E8  | Вход или приземление на предвестника        | Плакальщик ложится сразу при выкладке, узник попадает в яму и падает без потерь                                                                    |
